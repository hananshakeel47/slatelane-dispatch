# Project Vision

Build a production-grade freight dispatch CRM that allows dispatchers to:

- Manage leads
- Manage carriers
- Import official FMCSA carrier data
- Track follow-ups
- Record notes and activities
- View KPIs
- Manage users and permissions
- Scale to production deployment
